Still running last year's GTM? The path we run now

Kaan UnSeptember 30, 202621 reactions · 4 commentsView on LinkedIn ->

  • GTM engineering
  • Lead qualification
  • Account tiering
  • Browser agents

I caught myself running last year's GTM. Waterfall on emails, hit send, wait. The replies came back dry, so we changed the whole path.

1. Write the brief

Write the ICP down in one brief and refer to it on everything. Every later step checks a row against that page, so it has to exist before the list does.

2. Build the list

Pull a TAM from that customer profile. Apollo.io is solid for this, but pull from a few sources if you want the list accurate. Merge the sources, clean the data, and keep one sheet for your prospects.

3. Qualify every account

Have a research agent read each account. Deep research works best. The hassle is spinning up a pile of agents, one per row, once the list gets long. We built PowerSell for exactly that step.

4. Tier the list

Cut the qualified list into four parts and give each its own channel.

  • Tier 1: people you want a real relationship with
  • Tier 2: call by phone
  • Tier 3: email and LinkedIn
  • Tier 4: cold email only

5. Run the browser loop

For the grind across tabs, put a browser agent on LinkedIn, Google Sheets and Gmail. Plenty of tools can run those steps. The idea is simple: find the accounts, write to the sheet, check replies, keep moving.

6. Close after the call

The call ends and most teams drop the ball here. Drop the notes into your CRM. Draft the follow up while it is fresh. Open the proposal so it is ready to send.

That last step is the same idea as our retention email loop: the summary goes out the same day.

The whole path

Brief, list, qualify, tier, browser loop, post call close. Run one piece well this week before you add the next.

Step two has its own note if you sell to local businesses: how to build a lead list from Google Maps.

Talk to your GTM engineering team about which piece you run this week. Talk to us if you do not have one.
